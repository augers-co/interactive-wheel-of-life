History

No snapshots yet. Save snapshot keeps a dated copy here, so you can see what has changed when you come back. Export file writes the whole wheel out to a file you keep — send that to your coach, or Import file to load one back in.

Scores, notes, actions and snapshots are kept in this browser's local storage on this device. Nothing is uploaded. Clearing site data would erase them, so use Export file if you are counting on the history months from now, or want to send your wheel to someone. Save as PDF produces a page you can read or hand over; Export file produces one that can be loaded back in and carried on with.
